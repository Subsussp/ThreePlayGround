# Three Playground
It's 
a web-based 3D editor built from scratch on top of [**Three.js**
](https://github.com/mrdoob/three.js/).


# Features 
- Easy to use Interface
- You can drop & drag geometries , materials , lights and composerEffects
- a Live viewport where you can control any object using on-screen controls
- Export Three js Code 
- Custom Presets (Unfinished)
- 3D models import 
# How to use it 
You can simply visit the website :) 

[![Click Here](https://img.shields.io/badge/Click%20Here-blue?style=for-the-badge&logo=vercel)]()
 


# Inspiration
So when I try to create a new three js project I get annoyed by how much work I have to do just to add a simple cube so I'm creating this tool that will help me with building my portifolio project and help anyone who needs this
